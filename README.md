# Bara-bara-watch
A multi watch website where you can watch multiple youtube videos at once

You can search for different videos from youtube and add them as a pov to watch.

There is a limit of 4 video povs at once, and ui will reflec how many is being watched.

It shows how many is the limit in the top bar so its easy to see and more intuiative 

When a user starts to type in the search or click a "add stream button"  a modal opens and the user can search and see results and be able to add it to one of the iframes
